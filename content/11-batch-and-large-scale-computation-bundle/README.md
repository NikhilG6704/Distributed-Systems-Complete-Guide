# Chapter 11 — Batch and Large-Scale Computation

This bundle contains the completed Markdown chapter and all 19 SVG diagrams generated for its Phase 2 workflow.

## Contents

- `11-batch-and-large-scale-computation.md` — complete chapter with embedded relative image links.
- `assets/` — 19 standalone SVG diagrams referenced as `./assets/<filename>.svg`.
- `previews/` — rendered PNG previews and a contact sheet of all diagrams.

## Usage

Keep the Markdown file, `assets/`, and `previews/` together. Open the Markdown file in VS Code or GitHub; all embedded figures use relative paths and have no external asset dependencies.
